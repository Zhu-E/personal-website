    Typst Local

    GitHub ↗

    A self-hosted, real-time collaborative Typst editor. Run it on one machine and everyone on the network can edit together in the browser, with a live preview.

    • JavaScript
    • Rust
    • Node.js
    • Yjs
    • CodeMirror 6
    • WebSockets
    • Docker
    Details
    • Real-time collaboration over Yjs CRDTs, with everyone's cursors and selections shown by name
    • Recompiles on every change and pushes only the pages that changed, using a Rust compile engine to keep previews fast
    • Version history where every version is a real git commit, so a project's history can be cloned over HTTP
    • Exports to PDF, to a Word document styled to match the PDF, and to a source zip
    • One setup script for macOS and Debian-based Linux, or run it as a Docker container

    Endless Waves

    Open ↗ GitHub ↗

    An infinite ukiyo-e seascape in the style of Hokusai, drawn entirely with code. It's the banner on my homepage.

    • JavaScript
    • Canvas 2D
    • Procedural generation
    Details
    • Deterministic from a seed in the URL, so a given #seed is always the same sea
    • Great waves built from tapering spiral bands with branching claws of foam
    • Coastlines, villages, torii gates, ships and mountains placed on jittered grids, so nothing repeats or clumps
    • Rendered in cached chunks with woodblock paper grain and slightly off-register ink outlines

    Google Drive RAG

    GitHub ↗

    An end-to-end RAG assistant that answers questions from your own Google Docs.

    • Python
    • OpenAI API
    • Vector embeddings
    • Pandas
    • Google OAuth
    • Google Drive API
    Details
    • Connects to a user's Google Drive securely through Google OAuth
    • Pulls documents with the Drive API and stores their content as CSV
    • Embeds each document with OpenAI's Embedding API and ranks them against the query with vector search

    Twitch Clip Compilation Bot

    GitHub ↗

    Finds the most popular clips on Twitch, cuts them into a single compilation and uploads it to YouTube, with no manual editing.

    • Python
    • Twitch API
    • Selenium
    • FFmpeg
    • YouTube API
    • Google OAuth
    Details
    • Pulls a configurable number of top clips for a chosen time window from the Twitch API
    • Downloads the clips with Selenium-based web scraping
    • Merges and formats them into one highlight video with FFmpeg
    • Uploads the result through the YouTube Data API, authenticated with Google OAuth
